Fit check

Paste the role. It answers with evidence, or says it can’t.

Every portfolio argues it is a fit for everything. This one will tell you where it isn’t. Paste a job description and it matches your words against an index built from the pages of this site — each claim comes with the page you can check it on, and anything it has no evidence for is listed as exactly that.

It matches. It does not generate. There is no model here and no text is written on the fly. It is a lexicon and a fixed index, both readable in the JSON it loads. That is deliberate: a tool that made up an answer about someone’s experience would be the exact failure the rest of this site is about.

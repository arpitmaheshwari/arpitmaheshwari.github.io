## The research note is the keeper

`ai-product-designer/notes/awwwards-study.md` surveyed ~40 Awwwards collections and concluded:
the award-portfolio formula (preloader → kinetic hero → hover-distortion gallery → oversized
email → custom cursor) **optimizes for awards juries, not hiring managers** — and that
decision-level evidence, outcomes-on-the-surface, and scannability are essentially ABSENT from
that canon. That is the same thesis this site already runs on, reached independently. Keep the
note even if every visual here is discarded.

## FABRICATION AUDIT — the reason none of these ships as-is

Audited every numeric/factual claim across all 12 files against CANONICAL-FACTS.md.

**Invented, not in canon — must never be copied out of these files:**
- `Theme 4 - Calibration`: **"user trust after design: 0.94 · before: 0.31"** — no such
  measurement exists. It is the hero centrepiece of that theme, which is what kills the theme.
- `ai-product-designer/Portfolio Concepts`: **"Revenue retention 118%"** — not in canon.
- `The Seam` + `redesign-concept/Concepts`: **"6-qtr rolling baseline"** for the $1M — canon
  says *vs 2016 print budget*.
- `The Seam`: **"output: 92%"** presented in the hero as a site claim; traceable only as a
  loop.js demo default.

**Canon style violations:**
- Themes 3, 4 and 6 all write **"−$1M / yr"** with a minus sign. Canon: never write a saving as
  a negative. Theme 3 additionally prints "0 fabricated metrics" in the same ticker strip that
  carries the `−$1M` — claim and violation in one line.

**Checked and genuinely CORRECT** (verified, expecting failure, found none): `£69,000` average
media-value uplift per client; `Q3 2017 → Q3 2018` for the 0% → 64% subscription shift.

## Verdict (2026-08-09)

- **The Seam** — the only structurally original idea: a literal vertical seam splits every
  section, machine (mono, readouts) left / human (serif, prose) right. The layout IS the thesis.
  Costs: the dark band eats horizontal space; needs 2 invented numbers removed.
- **Theme 1 — Warm Gallery** — safest genuine upgrade. Light-mode version of the current palette;
  its hero line ("The model is right. The person hesitates. I design the hesitation.") is sharper
  than the shipped one. **Its case index is near-identical to the S2 index shipped 2026-08-08** —
  independent confirmation that S2 was the right call.
- **Not recommended:** Theme 5 (scroll-jacked; static render shows a ~700px void), Theme 3
  (loud enough to compete with the evidence), Theme 4 (concept rests on the fabricated number).

**RULE: if any copy or number is lifted from these files into a shipped surface, it must be
re-verified against canon first.** These were generated by a tool with no access to
CANONICAL-FACTS.md, and four invented facts prove it.

Styling is directional; the picked option gets rebuilt properly on the live surface.

Option A — the verdict slip

The bet: the skim layer becomes another cream evidence object — the site already teaches reviewers that paper artifacts carry the verified facts (receipts, candidate facts, boarding pass). Product screen sits beside it, visible without scrolling. The cost: a second dense object in an opener that already has vitals and provenance rows — the hero gets busier.
